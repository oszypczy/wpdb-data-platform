During long builds (stage 3 took several hours) the user sends short Polish check-ins like
"jak tam ci idzie? Ile % +/-?" or "a teraz ile %?".

**How to apply:** reply in Polish, 3–5 lines: an overall percentage, what is done (by part
A/B/C or by component), what remains, then continue the task without waiting for an answer.
Keep the final report in the language the orchestrator asked for (English).
